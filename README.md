# Abyssal

Um jogo 3D de terror e labirinto desenvolvido em Unity para VR.

## Como Abrir e Rodar o Projeto

### Pré-requisitos
* Baixe e instale o [Unity Hub](https://unity.com).
* Instale a **versão correta do Unity** usada neste projeto (veja a versão recomendada abaixo ou chegue na aba *Installs* do Unity Hub).
  * **Versão do Unity:** `6000.0.33f1`

### Passos para executar
1. Clone este repositório ou baixe o projeto em formato `.zip` e extraia em uma pasta:
   ```bash
   git clone https://github.com
   ```
2. Abra o **Unity Hub**.
3. Clique no botão **Add** (Adicionar) no canto superior direito.
4. Selecione a pasta raiz do projeto clonado/extraído.
5. Clique na linha do projeto na lista do Unity Hub para abri-lo (a versão correta será aberta automaticamente se estiver instalada).
6. No Unity Editor, vá até a aba **Scene** (ou abra a pasta `Scenes` em `Assets/Scenes`), escolha a cena principal e clique no botão **Play** no topo da tela.
